# Gridfinity Miniature Holders

Was talking with a friend and they printed [this kill team carry case](https://www.myminifactory.com/object/3d-print-simple-mini-storage-kill-squad-all-in-one-carry-case-412299). They then asked about ModiBoxi since it's all modular and assemble to what you want with a similar hold down mechanism to the above. I went through what they offer, and think it's neat. There's a lot of competition with like SuperProBox, OmniCase, Vaikin Box, and all the other ones. The thing that I want in an organizational system is to be open specification. I want open spec systems cause I want to know I'm allowed to make my own things for the system. Cases like, that one mini with a different base, that one extra tall mini, my printer is too small, my printer is huge, I need a kill team, I need a tarrasque, I want my cards with it, and every other use case that exists. For that I want an open specification, which none of the above are from what I found. 

[Gridfinity is](https://gridfinity.xyz/specification/). 

## What is Gridfinity

Gridfinity is an open spec grid based modular system for displaying and storing tools. Super reductive, [here's the creator in the initial release of the system though](https://www.youtube.com/watch?v=ra_9zU-mnl8). Also, [I've wrote about gridfinity](https://blueshirt.dev/2023/01/14/gridfinity-things-and-thangs.html) as well as, [how I use gridfinity for transporting items](https://blueshirt.dev/2023/06/02/gridfinity-on-the-go.html). So there is a small chance, of a minor case, of significant bias. I think that bias is justified in if a creator or designer wins a lottery and decides a life on the beach never looking at a computer again is for them, now the system is not supported. No new updates, no new fixes, no new inserts for FliggleFlabble, the hit new table top 20,000 point army system that uses inverted round bases. Gridfinity on the other hand, open spec. If anything happens to the creator, (only good things please), then all that is needed to make adjustments is already available. The community support around it makes that even easier in all the designs they've released, and even, code that this project started with.
